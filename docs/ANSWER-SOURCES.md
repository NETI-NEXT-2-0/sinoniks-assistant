# Источники справочных ответов — задача 05

Из карточки цитаты можно открыть актуальный фрагмент и, при отдельном праве,
скачать оригинал. Историческая цитата остаётся частью сохранённого ответа;
повторное открытие исходника проверяется сервером заново. Закрытие карточки
сбрасывает загруженный фрагмент. Ошибка доступа убирает его, не выдавая её за
отсутствие сведений в документе. Просмотр не обращается к модели.

## API

`GET /api/v1/runs/{run_id}/citations/{index}` возвращает текущие `title`,
`excerpt`, `location`, сохранённую `quote`, `evidence_id`, `web_source` и
`original_download_path` либо `null`. Индекс — 0–49. Проверяются:

- владелец неудалённого чата и завершённый успешный Run;
- принадлежность цитаты его ContextManifest;
- действующая версия, публикация, допуск фрагмента и актуальные права;
- точное вхождение цитаты в текущий текст с нормализацией пробелов;
- для вложения — собственник, тот же чат, готовность/хеш и отсутствие удаления.

Метаданные названия и раздела берутся с сервера. Неизвестная/чужая цитата —
404, изменённый источник — 409 `source_context_changed`; вложение другого
чата или удалённое вложение также может вернуть 404. Ответ — private/no-store.
Архив без пригодного manifest не получает права открыть произвольный источник.
Сохранённые сообщения и цитаты этим API не переписываются и не удаляются.

Право на ответ не разрешает оригинал. Для базы знаний доступная ссылка ведёт
на существующий защищённый `POST /knowledge/versions/{version_id}/original/download`;
он повторно проверяет право и байты непосредственно при скачивании. Отзыв права
после открытия карточки блокирует download. Новый download личных вложений
этот блок не добавляет: их фрагменты доступны, ссылка на оригинал — `null`.

## Проверки

- `integration/test_answer_sources.py`: 10 случаев — реальный текст/локатор,
  поддельные метаданные, чужой администратор и владелец документа вместо
  владельца чата, неизвестные индексы, отзыв прав, запрет фрагмента, снятие
  публикации, статус версии, download после отзыва, manifest и личные вложения.
- `scripts/ci/browser_answer_sources.py`: настоящий UI и сервер; отдельный
  куратор меняет права. Проверены раскрытие, текущий раздел, разделение прав,
  отказ скачивания после отзыва, закрытие/повторное открытие, отзыв чтения.
  Требуются `PARTNER_DIAGRAM_FIXTURE_CONFIRMED=1`, приватный
  `PARTNER_SOURCE_BROWSER_ACCOUNT_FILE` с одноразовыми аккаунтами/ID фикстура
  и при необходимости `CHROMIUM_PATH`. Один синтетический модельный ответ,
  открытие/повтор источников не добавляют вызовов.
- `integration/test_knowledge19_publication.py`: настоящий корпус, PostgreSQL,
  объектное хранилище и отдельный Qdrant. При заданном приватном
  `PARTNER_KNOWLEDGE19_REFERENCE_CHECKS` три вопроса Q01/Q10/O01 проходят
  извлечение, заменённый ответ провайдера, проверку точной цитаты и новый API.
  Манифест — массив `{id, query, facts: {name: regex}}`; он используется только
  как явно переданный тестовый контроль, не как продуктовая логика поиска.
  Reader получает оригинал только после отдельного grant, SHA-256 совпадает
  с загруженным файлом, отзыв права снова даёт 404. Исходники и ответы приватны.
