# Диалог, проект и база знаний — 21 ноября 2026

## Проверенные причины

В последних проверенных запусках Polza были отказ цитаты
`provider_unauthorized_citation` и `provider_request_timeout`. Провайдер
при этом действительно вернул `openai/gpt-6-luna`, токены и рублёвый usage.
Это разные причины; их нельзя исправлять одним повышением температуры.
Старые отказы Terra `provider_invalid_rag_json` сохранены как исторические.

В `answer_history` ответы `insufficient` без источников пропускались.
Поэтому пара «Добавь компьютер 3 справа» → «В какую сеть добавить?»
исчезала перед коротким «Сеть цеха». Теперь эта пара остаётся контекстом
диалога. Прежние ответы по-прежнему не являются источниками фактов.
Владелец/ветка/ревизии/права источников проверяются прежним механизмом.

В контекст сохранённого расчёта добавлена фактическая карта левой/правой
сети по `node_a_network_id` / `node_b_network_id`. Она не определяется
по названию сети и отсутствует без сохранённого размещения. В Reference
контекст проекта по-прежнему не передаётся.

Polza получает `response_format=json_object`, только разрешённый маршрут
Flex и запрет fallback. Разрешён единственный полный Markdown-блок JSON;
не принимаются произвольный текст вокруг него, несколько объектов,
повторные ключи, нечисловые числа, чужие цитаты и некорректный проект.
Промпт отдельно объясняет, что проектные ID не являются evidence ID,
и позволяет связывать короткий ответ с предыдущим вопросом.

Сообщения об ошибках различают таймаут, неподтверждённую цитату и неверный
формат. Проект при таком отказе не изменяется. Безопасная предварительная
диагностика из ранней версии PR18 проверена локально; более поздний полный
model_response/debug UI и изменения контракта из обновлённого PR18
этим этапом не включаются. У исходного PR менялась вершина во время работ;
состояние CI его новой версии не объявляется CI текущего develop.

## Рабочая область проекта

Сохранённая схема/правила и редактирование условий разделены переключателями.
Новый проект сразу открывается в редакторе 1.9; переход старой версии остаётся
явным. Оба раздела сохраняют своё состояние, скрытые контролы не входят в
ловушку фокуса. Несохранённые условия не выдаются за обновлённую схему.
Шапка показывает версию и действие «Сохранить и рассчитать»; прежний
идемпотентный обработчик, конфликт версий и подтверждение выхода сохранены.
Остаётся одна таблица правил, пояснение архитектуры открыто, draw.io выделен.
Палитра, расчёт и содержимое экспортируемой инженерной схемы не меняются.
Ввод чата уменьшен: убраны складывающиеся вертикальные padding/min-height;
многострочный ввод и touch-цели сохраняются.

## Источники и импорт

По поручению владельца подготовлено17 источников: три Markdown-материала1.9,
девять PDF, DOCX со сценариями продукта, три RFC и краткая составленная
справка по официальной странице. Исходники сохраняются с SHA256; импорт
идёт через admission, оригинал, штатное распознавание, проверенную копию,
Qdrant staging и публикацию. Эмбеддинги не добавляются.

Партнёрские оригиналы и исходные рабочие файлы не публикуются в Git.
Контрольные benchmarks, шаблоны эталонных решений и задания оценки не
попадают в retrieval. Старые документы и ACL не перезаписываются.
Публикация от имени существующего администратора; право ответов выдаётся
существующим активным учётным записям, право скачивания оригинала отдельно
не расширяется. Новые аккаунты подчиняются прежней политике доступа.

Общие справки не доказывают возможности продукта и не переопределяют
методику1.9. Название источника/версии передаётся рядом с фрагментом.
Материалы об устройстве разных лет остаются явно названными источниками.

Общие источники:
- [RFC5424 — Syslog](https://www.rfc-editor.org/rfc/rfc5424.txt).
- [RFC5426 — Syslog over UDP](https://www.rfc-editor.org/rfc/rfc5426.txt).
- [RFC5905 — NTPv4](https://www.rfc-editor.org/rfc/rfc5905.txt), базовая спецификация2010года, имеет последующие обновления.
- [Официальная страница Синоникса](https://it-bastion.com/products/sinoniks/):
  просмотренная составленная справка; полная HTML-копия не скачана из-за TLS-сбоя.

На промежуточном этапе все оригиналы уже загружены; публикация распознанных
PDF и проверка поиска продолжаются. У технической презентации получен
CanonicalError/блок качества: он не обходится и не считается успешной публикацией.
