Техническое задание определяет ожидаемый продукт и критерии оценки. Факты о возможностях устройства сверяются с `01_scope_functions_synonyx_1.9.md`, правила расчёта и графики — с `02_methodology.md` и уточнениями ТЗ, термины — с `03_glossary.md`. Изображения, презентации и описание других платформ дополняют контекст. Для проверки используются оригинальные `04_benchmarks.json`, шаблон `06_template.drawio`, примеры `05_pattern_F02.drawio`, `05_pattern_F07.drawio` и `result.example.json` из комплекта. На выступлении сквозной путь с уточнениями, схемой и правками обсуждается на 09:54–11:06, ограничение цены входа — на 11:06–11:24, чекпоинт — на 12:07–12:27, полная стоимость диалога — на 15:15–15:48, проверка репозитория — на 15:58–16:33. Для зачёта применяются письменные критерии ТЗ, включая максимум 10 баллов за экономичность.
